# inhalte/

Zielordner von `tools/export-inhalte.php`. Hier liegt nach dem Export das Ausgangsmaterial
für die Fallback-Muster (`patterns/inhalt-<slug>.php`). Wird **nicht** ausgeliefert.

- `index.json`, `<slug>.html`, `menus.json`, `site.json` – vom Export erzeugt
- `AUFFAELLIGKEITEN.md` – legt Cursor beim Umwandeln an (Tippfehler, veraltete Termine, kaputte Links)
- `startseite.vorlaeufig.md` – Texte der Startseite (Stand 29.10.2026, von der Live-Seite
  gelesen), bis der Export vorliegt. Der Export hat Vorrang.
